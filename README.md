# 밸류업(기업가치 제고) 공시 알림 시스템

기업가치 제고 공시를 계속 모아 두었다가 **영업일 09:00·15:30 하루 두 번** 팀 텔레그램방에 정리해서 보냅니다.

- ✅ **인정 기준**: PDF·한글·워드 첨부가 있는 공시만 (첨부 없이 본문만 낸 고배당기업 공시 등은 제외, 나중에 첨부가 올라오면 다음 리포트에 포함)
- 🟦🟩 **계획/이행 구분**: 공시명 괄호, 본문 '계획서 명칭', 첨부 파일명으로 판별
- 💰 **시총·종가**: 15:30 전엔 전일 종가, 15:30 이후엔 당일 종가 기준
- 👤 **담당자 자동 지정**: 팀이 함께 고치는 커버리지 원본 파일(공유폴더 엑셀 또는 구글시트) 기준
- 🖥 **대시보드**: 전체 공시·진행상태(미착수/작성중/완료/제외)·내 할 일·리포트 미리보기

## 1. 준비물

| 항목 | 방법 |
|---|---|
| DART API 키 | 보유 중인 키 (상장사 코드표·주식수·백업 감지에 사용) |
| 텔레그램 봇 | 텔레그램 **@BotFather** → `/newbot` → 토큰 복사 |
| 팀방 chat_id | 팀방에 봇 초대 → 프로그램 실행 후 방에서 `/chatid` |
| 커버리지 원본 | 아래 2번 참고 |
| (선택) Anthropic API 키 | 넣으면 첨부 PDF를 개조식 요약해 리포트 ▸ 줄에 사용 |

> `/chatid`가 응답이 없으면 BotFather에서 `/setprivacy` → Disable 후 봇을 다시 초대하세요.

## 2. 커버리지 관리 (원본 파일 하나가 기준)

**원본은 시스템 밖의 파일 하나**이고, 시스템은 5분마다 + 리포트 직전에 읽어서 바뀐 게 있으면 반영합니다.
팀원은 평소처럼 엑셀/구글시트만 고치면 됩니다.

| 방식 | 설정 | 특징 |
|---|---|---|
| 공유폴더 엑셀 (권장) | `.env` → `COVERAGE_FILE=\\fileserver\리서치\밸류업\coverage.xlsx` | 사내 공유폴더·원드라이브 동기화 폴더 모두 가능 |
| 구글시트 | `COVERAGE_URL=https://docs.google.com/spreadsheets/d/<ID>/export?format=xlsx` | 링크 보기 권한 필요. 여러 명이 동시에 수정 편함 |
| 기본값 | 설정 안 하면 `data/coverage.xlsx` | 대시보드 업로드로 이 파일을 덮어씀 |

- 열: **애널리스트 · 종목코드 · 종목명** (코드나 종목명 둘 중 하나만 있어도 됨. `A005930`, `5930`도 인식)
- 애널리스트별 시트로 나눠도 되고(시트명 = 이름), 첫 행에 이름·아래로 종목 나열한 가로형도 됩니다.
- 한 종목을 여러 명이 맡으면 모두 담당자로 표시(👥 공동).
- 종목명으로 코드를 못 찾은 줄, 파일을 못 읽은 경우는 대시보드 **커버리지** 화면에 경고로 뜨고, 그동안은 직전 커버리지를 그대로 씁니다.
- 연초 종목 풀 교체 = 원본 파일 내용만 바꾸면 끝.

## 3. 설치·실행

**A. 사무실 PC(윈도우)**: Python 3.11+ 설치 → `.env.example`을 `.env`로 복사해 키 입력 → `start_windows.bat` 실행 → `http://localhost:8000`
(팀원은 `http://<PC 내부 IP>:8000`. 09:00·15:30에 PC가 켜져 있어야 함)

**B. 상시 서버(권장)**:
```bash
cp .env.example .env   # 키 입력
docker compose up -d
```
- **국내 IP** 서버 권장(KIND·네이버 시세가 해외 IP를 막는 경우가 있음).
- 외부 공개 시 `DASHBOARD_PASSWORD` 설정.

처음 실행 시 최근 30일치 공시는 **리포트 없이** 대시보드에만 채웁니다. 그 이후 공시부터 리포트에 들어갑니다.

## 4. 판별·계산 기준

**계획 / 이행**
- KIND 공시명은 대부분 `기업가치 제고 계획(자율공시)`로만 나와서, 본문 **계획서 명칭**(예: "2026 ○○ 기업가치 제고 계획 이행현황")과 괄호·첨부 파일명을 같이 봅니다.
- `이행` 포함 → **이행** / "이행현황 및 2026년 기업가치제고계획" → **이행+계획** / 고배당기업 표시용 재공시 → **재공시** / 나머지 → **계획**
- `예고` 공시는 제외, `[기재정정]`은 🔁 표시

**시총·종가**
- 종가: 네이버 일봉. 영업일 15:30 이후면 당일 종가, 그 전(09:00·15:30 리포트 포함)이면 직전 영업일 종가.
- 시총: 종가 × 보통주 발행주식수(DART 최근 정기보고서의 '주식의 총수'). 분기 사이 유상증자·소각은 다음 보고서부터 반영되니 큰 자본변동 직후엔 HTS와 차이 날 수 있습니다.
- 영업일: 주말·공휴일·대체공휴일·선거일·12/31 자동 제외. 임시 휴장일은 `data/krx_holidays.txt`에 날짜만 추가.

## 5. 점검용 명령

```bash
python run.py --test-telegram           # 팀방 테스트 메시지
python run.py --check 20260930000281    # 공시 1건의 첨부·본문·계획/이행 판별 결과
python run.py --price 388050            # 종가·시총 조회 확인
python run.py --preview                 # 다음 리포트 미리보기 (발송 X)
python run.py --digest-now              # 리포트 지금 발송
python run.py --backfill 90             # 과거 90일 조용히 적재
python -m pytest tests                  # 테스트 (네트워크 불필요)
```
대시보드 **리포트** 메뉴에서도 미리보기와 즉시 발송이 됩니다.
